# Modelagem de Banco de Dados para E-commerce

## Sobre o Projeto

Este projeto apresenta a modelagem de um banco de dados relacional para um sistema de e-commerce, desenvolvido no MySQL Workbench.

O modelo foi estruturado para organizar informações de clientes, produtos, pedidos, pagamentos e entregas, considerando as principais operações de uma plataforma de vendas online.

## Estrutura do Banco de Dados

A modelagem contempla sete entidades principais: Cliente, Produto, Pedido, Item do Pedido, Forma de Pagamento, Pagamento e Entrega.

A estrutura considera a diferenciação entre clientes Pessoa Física (PF) e Pessoa Jurídica (PJ), o cadastro de múltiplas formas de pagamento e o acompanhamento das entregas por status e código de rastreamento.

Os relacionamentos foram definidos utilizando chaves primárias e estrangeiras, buscando garantir a organização e a integridade das informações.

## Tecnologias Utilizadas

- MySQL Workbench
- Modelagem Entidade-Relacionamento (MER)
- Banco de Dados Relacional
- GitHub

## Considerações Finais

O projeto demonstra a aplicação prática de conceitos de modelagem de dados, organização de entidades, definição de relacionamentos e estruturação de regras de negócio.

A estrutura proposta serve como base para o desenvolvimento de um sistema de gerenciamento de vendas online e poderá ser expandida com novas funcionalidades.
